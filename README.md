# multi-marker-projecct

Описание проекта

Многомодульный проект магазина.
Состоит из 2 приложений:

-Маркет(market)
-Сервис платежей(payment)

Детальное описание каждого находиться в market и payment соответственно.

Сборка приложения:

mvn clean install в корне главного проекта соберёт оба вложенных приложения, но их можно собирать и по отдельности.

Приложение market зависит, от приложения payment, т.к в нём находиться файл payment.yaml, который отвечает за генерацию
клиента
для взаимодействия с сервисом payment
