# payment

Описание проекта

Приложение представляет простой сервис платежей с 2 API:

-Проверка текущего баланса пользователя

-Списание суммы с текущего баланса пользователя

-Для простоты реализации сумма баланса устанавливается в application.yaml как константа

Приложение разрабатывается как исполняемый JAR-файл

Сборка приложения:

Приложение собирается в исполняемый JAR-файл с помощью Maven:

mvn clean install

Деплой приложения:

Запустить исполняемый jar из консоли java -jar payment.jar

После запуска приложение станет доступно по адресу http://localhost:8081/

Для сборки приложения в docker образ нужен установленный docker и выполнение следующих шагов:

- Перейти в корень проекта
- Выполнить  "docker build -t payment .", где market имя желаемого образа
- Выполнить "docker run -p 8081:8081 payment", первый порт это порт хостовой машины, а 2 внутри docker контейнера

Порт для приложения или внутри docker контейнера можно настроить в соответствующем конфигурационном файле
application.yaml

Так же для корректной работы приложения необходим настроенный keycloak и прописать необходимые конфигурации в
application.yaml
